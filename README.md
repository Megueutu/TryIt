# TryIT

Laboratório de exercícios de programação em múltiplas linguagens. O frontend usa Vue 3, TypeScript e Vite.

## Desenvolvimento local

Use Node.js 24 LTS com npm.

```sh
npm ci
npm run dev
```

Execute `npm run build` para verificar os tipos e gerar o frontend em `dist/`. Use `npm run preview` para testar o build localmente.
